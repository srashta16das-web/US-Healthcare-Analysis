# US Healthcare Analysis

Analysis of 55,500 US hospital admissions (May 2019 – May 2024): admission volume, billing, length of stay, insurers and test results.

**Dataset:** [Healthcare Dataset (Kaggle, prasad22)](https://www.kaggle.com/datasets/prasad22/healthcare-dataset). The data is synthetic (randomly generated).

## Repository structure

| Folder | What it contains |
|---|---|
| [`01_Raw_Dataset/`](01_Raw_Dataset/) | The original `healthcare_dataset.csv`, unchanged |
| [`02_Cleaned_Dataset/`](02_Cleaned_Dataset/) | The dataset after cleaning |
| [`03_Report&Analysis/`](03_Report&Analysis/) | Working files: pivots, charts, statistical tests |
| [`04_Report/`](04_Report/) | Final dashboard, summary report and presentation |

## Key questions

1. What are admission volume, total billing, average bill and average length of stay (LOS)?
2. How do bill and LOS vary by medical condition, admission type, insurer and age group?
3. Which insurers bring the most revenue?
4. Are test results related to condition or medication?
5. Are there trends or seasonality in admissions?
